# Build from instructions alone

Build a memory matching game that can be played in a browser.

Use a 4-by-4 grid of cards, and display the move count and a game-complete message. Let the player reset and play again. Make the interface easy to use on a smartphone.

Do not add new dependencies or access anything outside the working directory. Use only `npm run typecheck`, `npm test`, and `npm run build` for verification. Do not perform browser checks; report the items that a person must verify.
