## Failures and staged improvements

1. Gemma repeatedly attempted exact-string edits with a mismatching quote in the multi-file fixture. The unchanged operation failed repeatedly until the budget ended. First evaluate a test-local instruction to re-read the file after a failed edit and choose a different edit, using the same fixed case denominator. No claim is made that this prompt change already improves outcomes.
2. The runtime currently exposes a generic preparation/authorization error for this failure. More actionable bounded edit diagnostics may improve recovery, but changing safety-sensitive failure disclosure requires research and an approved ADR. Production error handling was not changed.
3. Ornith can solve the multi-file case, but repeated budget/deadline failures prevent a general reliability claim. Next isolate host scheduling and capture model load/evaluation durations before increasing the benchmark size or choosing a larger model.
4. Test-local fixes made here: preserve test-failure evidence when a shell echo masks exit status; separate budget stops from runtime errors; disable Mocha timers in favor of host-owned cleanup; require a fresh grader completion marker; normalize diff headers without rewriting file contents. Five unit tests and four Docker grader controls cover the key failure modes.
