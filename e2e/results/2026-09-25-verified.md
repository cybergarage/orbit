## Solver findings

Django's raw generated patch passed all official checks (1 FAIL_TO_PASS and 58
PASS_TO_PASS), but the Run ended at its 50-iteration budget. The patch was not
manually corrected. The model completed focused `bulk_create` and
`custom_managers` checks, then expanded to additional suites, including guessed
suite names that did not exist. Its final work therefore did not reach a normal
completion response despite a passing patch.

Several solver commands piped output through `tail`, masking the test command's
exit status. Console text revealed import/path and test-selection failures even
where the shell/tool result appeared successful. This does not invalidate the
independent official grading; it identifies weaknesses in local test execution
and completion decisions. Useful next experiments should isolate environment
instructions, discovery of valid test commands, preservation of test exit status,
and a focused stopping rule. Increasing the product-wide iteration default is
not established as the remedy by this sample.

pytest's patch applied successfully, but official grading found the required
FAIL_TO_PASS test still failing and one PASS_TO_PASS regression (14/15 retained).
The model replaced list reassignment in `LogCaptureHandler.reset()` with in-place
clearing. The failing checks cover call-stage clearing and preservation across
logging stages; the observation is a real unresolved patch, not a harness error.
The Run also reached its iteration budget (54 tool calls across 50 tool rounds).

Its local investigation spent many calls on Python package/import compatibility
and ad hoc test shims. The generic solver environment is therefore a material
limitation in attributing this failure to model capability alone. A separate
controlled experiment should preflight the target repository's own test command
and source import path, without giving it hidden test names or patch hints.
Keep this original failed trial when comparing any such environment repair.

Sphinx's patch passed all 41 official checks but did not complete normally.
It changed the order of dedenting and prepend/append filtering. Its local checks
showed two pre-existing test failures also reproduced after temporarily
reverting the production edit. A newly added reader-level test passed, while a
newly added document-level test was still failing at the last recorded run.
The raw patch retains that test and `.pytest_cache` files. Thus, the official
problem is resolved, but this patch is not a clean, fully verified deliverable.

## Improvement priorities

1. **Preflight repository test execution.** Verify the target source import path,
   public dependencies and a known existing test command before assigning the
   problem. Keep the solver environment and official grading environment
   explicit. pytest spent much of its budget on import/package setup; simply
   enlarging the budget would also enlarge that setup cost.
2. **Make test status and completion explicit in the evaluation instructions.**
   Preserve the original test exit status when truncating output, discover valid
   test names from the repository, and stop after focused regression evidence
   is sufficient. Django produced a correct patch and passed focused checks
   before expanding into guessed/nonexistent test suites. Test these instruction
   changes separately; the earlier recovery bundle did not generalize to SWE.
3. **Check the complete deliverable separately from benchmark resolution.**
   Include the agent's newly added tests and unwanted generated files in an
   additional quality report. Preserve the unmodified official score and raw
   patch; do not silently filter a submitted patch to make it look cleaner.
4. **Then compare budgets on held conditions.** This sample does not justify
   raising Orbit's product defaults. Use a fixed environment and instruction
   variant to compare normal completion, official success, usage and regression
   failures, retaining all failed trials.

These are proposals from the observations, not implemented product behavior.
No additional model attempt was made after seeing the grades; this preserves the
preselected one-attempt-per-problem record.
