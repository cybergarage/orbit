# Improve autonomously with specifications and tests

Review `spec.md`, `test.md`, and `progress.md`.

Implement the features in `spec.md` and create tests according to `test.md`. Repeat implementation, type-checking, testing, building, and correction, and record verified results in `progress.md`.

Follow these conditions:

- Do not change `spec.md` or `test.md`.
- Do not add features that are not in the specification.
- Do not add new dependencies.
- Do not access anything outside the working directory.
- Do not use network access, web search, or browser automation.
- Use only `npm run typecheck`, `npm test`, and `npm run build` for verification.
- Do not perform destructive Git operations.
- Do not mark browser checks as complete; report the items that a person must verify.
- When a stop condition is reached, report completed items, incomplete items, and command results.
